Qualität bedeutet mehr als Testanzahl
Abdeckungslücke

Testname und Testziel weichen ab

UserAuthServiceStudentTest testet tatsächlich UserAuthController. Dadurch sind die Fälle weitgehend doppelt, während Service-Verhalten nur die reguläre Suite abdeckt.

Doppelte Fälle

Security und Web sind fast identisch

Filter, CORS und Exception-Handler prüfen in beiden Gruppen größtenteils dieselben Fälle. Das erhöht die Testzahl, aber nicht entsprechend die Verhaltensabdeckung.

Stärker regulär

Zusätzliche Grenzfälle

Die regulären Chat-Controller-Tests prüfen zusätzlich ungültige IDs. Die reguläre Auth-Suite enthält außerdem einen Passwort-Hasher-Test und mehr Service-Verhalten.

Ausführung: Der letzte Lauf von mvn verify führte alle 76 Tests aus: 0 Fehler, 0 Auslassungen. JaCoCo misst Ausführung/Branches; eine erfolgreiche Ausführung allein beweist nicht, dass ein Test eine Verhaltensänderung erkennt. PIT-Mutationsergebnisse sind in diesem Vergleich nicht enthalten.
